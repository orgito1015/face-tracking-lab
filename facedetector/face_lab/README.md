# Face Recognition and Tracking Simulation Lab

Lynn University x Universitetit te Tiranes - Informatica (April 2026)

## Project Structure

- `webcam_test.py`: Member 1 deliverable (webcam + FPS + timestamp)
- `face_detect.py`: Member 2 deliverable (Haar + MediaPipe backends)
- `pid_tracker.py`: Member 3 deliverable (MockTello + PID tracking + CSV logging)
- `analysis_plot.py`: Member 4 deliverable (3-panel tracking analysis plot)
- `rc_log.csv`: tracking log (generated by pid_tracker.py)
- `docs/member1` to `docs/member5`: templates and notes for each role
- `outputs/`: saved figures and screenshots

## Setup

1. Create a Python 3.11 or 3.12 environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Quick Run

### Member 1

```bash
python webcam_test.py
```

### Member 2

```bash
python face_detect.py --backend both --benchmark-seconds 30
```

### Member 3

```bash
python pid_tracker.py --duration-seconds 120
```

### Member 4

```bash
python analysis_plot.py --input rc_log.csv --output tracking_analysis.png
```

### Member 5

Use templates in `docs/member5/` to prepare the Joint Ethics Brief.
